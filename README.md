# İmran Neocities Dosya Merkezi v2
Bu sürüm klasör gezintisi, arama, tür filtresi, son güncellenme zamanı, son 7 günde değişen dosyalara YENİ etiketi ve açık/koyu tema içerir.
GitHub Actions yaklaşık 5 dakikada bir Neocities API listesini yeniler.
API anahtarını HTML içine koymayın; `NEOCITIES_API_KEY` GitHub Secret olarak kalmalıdır.
Neocities'in güncel izinli uzantıları arasında PDF, JPG/JPEG, PNG, GIF, SVG, HTML, CSS, JS, JSON vb. bulunur. MP4 ve DOCX/XLSX'i Neocities'in mevcut izinli liste­sinde varsaymayın.

## Saat dilimi
`Son liste` zamanı `Europe/Istanbul` kullanılarak Türkiye saatiyle (TRT, UTC+3) oluşturulur.
